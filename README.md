# 냥코 도감 (NyankoDex)

**👉 [냥코 도감 바로가기](https://crexont.github.io/nyanko-dex/)** · 현재 버전 **v1.0 베타**

냥코대전쟁(한국판)에서 **내가 가진 캐릭터의 진화 단계, 레벨, 본능 상태를 한눈에** 보고 관리하는 웹 도감입니다.

캐릭 수백 마리를 하나하나 입력하는 건 너무 노가다라서, **추출 도구**로 내 세이브를 한 번에 불러올 수 있게 했습니다. 불러온 다음에는 사이트에서 직접 고치면서 쓰면 됩니다.

- 입력한 데이터는 내 브라우저에만 저장됩니다. 어디로도 전송되지 않습니다.
- 추출 도구는 세이브를 **읽기만** 합니다. 세이브 수정이나 서버 업로드는 하지 않습니다.
- PONOS와 관계없는 비영리·비공식 팬 도구입니다. 사용 책임은 본인에게 있습니다.

## 기능

- **세이브 불러오기**: 추출 도구가 만든 `냥코_세이브.json`을 열거나 끌어다 놓으면 보유 캐릭이 한 번에 채워집니다.
- **직접 수정**: 캐릭 카드를 누르면 보유 여부, 진화 단계, 레벨+플러스, 본능 레벨을 고칠 수 있습니다. 세이브 없이 처음부터 직접 입력해도 됩니다.
- **자동 저장 · 백업**: 고친 내용은 브라우저에 자동 저장됩니다. [내보내기]로 파일 백업, 다른 기기에서 [세이브 불러오기]로 복원할 수 있습니다.
- **필터**
  - 보유 / 미보유 / 전체
  - 할 일: 3진 가능·미진화, 4진 가능·미진화, 본능 미해방, 본능 미완료, 레벨 미만렙
  - 레어도별, 속성(빨강·떠있음·검정·메탈·천사·에이리언·좀비·고대종·악마·무속성) 상대
- **검색 · 정렬**: 1·2·3진 이름 모두 검색, ID·레어도·레벨 순 정렬

## 세이브 불러오기 (추출 도구, Windows)

준비물: **블루스택 5**만 있으면 됩니다. Python이나 7-Zip은 따로 설치하지 않아도 됩니다.

1. [Releases](../../releases/latest)에서 `NyankoDex-<버전>-win64.zip`을 받아 원하는 폴더에 압축을 풉니다.
2. 블루스택 5에 냥코대전쟁(한국판)을 설치하고, 폰에서 발급한 **기종변경 코드**로 계정을 옮긴 뒤 게임을 한 번 실행합니다.
3. 블루스택을 **완전히 종료**합니다(작업 표시줄 트레이 아이콘까지).
4. `NyankoDex.exe`를 더블클릭합니다.
   - 같은 폴더에 `냥코_세이브.json`이 만들어지고, 도감 사이트와 파일 위치가 함께 열립니다.
5. 사이트에서 [세이브 불러오기]를 누르거나 `냥코_세이브.json`을 화면에 끌어다 놓습니다.

게임을 더 진행했다면 3, 4, 5번을 다시 하면 됩니다. 이때 사이트에서 직접 고친 내용은 새 세이브 내용으로 바뀝니다.

> **처음 실행할 때 "Windows의 PC 보호" 창이 뜨면** [추가 정보] → [실행]을 누르세요. 코드 서명을 하지 않은 개인 프로젝트라 뜨는 경고입니다.

### 계정을 폰으로 되돌릴 때

기종변경 코드는 한 번 쓰면 사라집니다. 블루스택에서 다시 기종변경 코드를 발급받아 폰에 입력하면 계정이 돌아갑니다. 이 과정은 게임의 정상 기능이며, 이 도구와는 관계없습니다.

## 추출 도구 동작 방식

1. 블루스택 인스턴스의 가상 디스크(`C:\ProgramData\BlueStacks_nxt\Engine\<인스턴스>\Data.vhdx`)에서 동봉된 7-Zip으로 `SAVE_DATA`만 꺼냅니다. 원본 가상 디스크는 읽기만 합니다.
2. [BCSFE](https://github.com/fieryhenry/BCSFE-Python)로 세이브를 읽어 보유 캐릭·진화·레벨·본능만 `냥코_세이브.json`에 담습니다.

인스턴스가 여러 개면 세이브가 가장 최근인 인스턴스를 고릅니다. 직접 지정하려면 명령 프롬프트에서 `NyankoDex.exe --instance Pie64`처럼 실행하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "블루스택이 실행 중입니다" | 블루스택을 트레이 아이콘까지 완전히 종료한 뒤 다시 실행 |
| "블루스택 5 인스턴스를 찾지 못했습니다" | 블루스택 5가 설치돼 있는지 확인 (블루스택 4 이하는 미지원) |
| "세이브가 있는 인스턴스가 없습니다" | 블루스택에서 냥코(한국판)를 실행해 계정을 옮긴 뒤 종료하고 재시도 |
| 백신이 exe를 막음 | PyInstaller로 만든 exe에서 생기는 오탐입니다. 백신에서 NyankoDex 폴더를 예외로 추가한 뒤 다시 실행 |
| 사이트에서 입력한 내용이 사라짐 | 브라우저 방문 기록·사이트 데이터를 지우면 함께 지워집니다. [내보내기]로 백업해 두세요 |
| 새 캐릭이 안 보임 | 게임 업데이트 후 도감 데이터가 아직 갱신되지 않았을 수 있습니다 |
